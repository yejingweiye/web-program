# 变更记录模板

在实施改动前填写，用于记录和分析变更影响。

---

## 基本信息

```yaml
标题: 
类型: feature | bugfix | refactor | security | db | docs
优先级: P0 | P1 | P2 | P3
预计工时: 
```

## 改动描述

```
当前问题 / 需求背景：

改动目标：

实现方案简述：
```

## 影响范围

```
□ 后端        — 涉及文件：
□ 前端        — 涉及文件：
□ 数据库      — 涉及表：
□ API 接口   — 涉及接口：
□ 配置文件   — 涉及配置：
□ 依赖/包   — 涉及依赖：
```

## 兼容性检查

```
□ 向后兼容（旧版本数据/请求不受影响）
□ 需要数据迁移（附迁移脚本）
□ 需要灰度发布
□ 需要通知前端/客户端更新
```

## 测试验证

```
□ 单元测试覆盖
□ 接口冒烟测试
□ 回滚方案：
```

## Review Checklist

- [ ] 命名符合项目规范
- [ ] 无敏感数据泄露
- [ ] 权限校验到位
- [ ] 异常处理合理
- [ ] 无 N+1 查询
- [ ] 与现有代码风格一致
- [ ] 测试覆盖核心逻辑

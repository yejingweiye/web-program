# 用户功能需求文档

## 1. 账号注册

### 1.1 需求描述
当前系统仅支持手机号+验证码登录（自动注册），缺少完善的注册流程。需要增加注册时的信息采集（昵称、年龄段、性别、城市），引导用户完善初始资料。

### 1.2 业务流程
```
输入手机号 → 获取验证码 → 验证通过 → 填写初始资料 → 注册完成 → 自动登录
```

### 1.3 字段要求
| 字段 | 必填 | 校验规则 |
|------|------|---------|
| 手机号 | 是 | 11 位数字，校验唯一性 |
| 验证码 | 是 | 6 位数字，有效期 5 分钟 |
| 昵称 | 是 | 2-20 字符，特殊字符过滤 |
| 性别 | 否 | 枚举：0未知/1男/2女 |
| 年龄段 | 否 | 下拉选择：18-24,25-34 等 |
| 城市 | 否 | 定位或手动选择 |

## 2. 账号注销

### 2.1 需求描述
用户可申请注销账号。注销为软删除，标记 `delete_flag=1` 并在 7 天后永久清理。注销期间用户可登录取消注销。

### 2.2 前置条件
- 用户已登录
- 无进行中的订单/活动

### 2.3 业务流程
```
用户申请 → 校验条件 → 标记注销(delete_flag=2) → 7天冷静期 → 永久删除
                          ↑                     ↓
                    用户取消注销 ← 登录时提示 ← 未进入永久删除
```

## 3. 用户黑名单

### 3.1 需求描述
用户可将其他用户加入黑名单，屏蔽其帖子、评论、私信。

### 3.2 功能点
- 添加黑名单
- 移除黑名单
- 黑名单列表
- 黑名单用户内容屏蔽（浏览帖子/评论时过滤）

## 4. 用户主页

### 4.1 需求描述
展示用户公开信息（昵称、头像、城市、实名等级、VIP 标识）和内容聚合（发布的帖子、参加的活动）。

### 4.2 信息分区
- **个人资料卡**: 头像、昵称、实名等级、VIP 标识、搭子标签
- **内容Tab**: 帖子 | 活动 | 评论

## 5. 账号安全设置

### 5.1 需求描述
提供账号安全管理功能。

### 5.2 功能点
- 修改手机号（需验证原手机号）
- 登录设备管理
- 账号操作日志
